# نصوص قوائم المتاجر — جاهزة للنسخ واللصق

## Google Play (تطبيق: تربح — `com.trbhh.app`)

**اسم التطبيق (30 حرفاً كحد أقصى):**
```
تربح | سوق تربح الإلكتروني
```

**الوصف القصير (80 حرفاً كحد أقصى):**
```
سوق إلكتروني سعودي: إعلانات، مبوبة، متاجر للتجار، شركات موثقة وتواصل مباشر
```

**الوصف الكامل:**
```
تربح — سوقك الإلكتروني الشامل للبيع والشراء في السعودية.

• إعلانات عرض وطلب في جميع الأقسام مع صور وتفاصيل كاملة
• الإعلانات المبوبة (حراج) بتصفح سريع وبحث ذكي
• افتح متجرك الخاص مجاناً: قوالب وثيمات جاهزة، رابط مباشر لمتجرك، وعرض منتجاتك في المنصة بعد اعتماد المتجر
• صفحات شركات موثقة وتقييمات للبائعين
• محادثات مباشرة بين البائع والمشتري وإشعارات فورية
• نشر إعلانك في أقل من دقيقة

حمّل التطبيق وابدأ البيع والشراء الآن.
```

**الروابط المطلوبة في القائمة:**
- سياسة الخصوصية: `https://trbhh.com/privacy`
- رابط حذف الحساب (نموذج أمان البيانات): `https://trbhh.com/delete-account`
- البريد: alaoufi@gmail.com

**الرسومات:**
- أيقونة 512×512: `public/icon-512.png` — أو 1024 من `public/play/store-icon-1024.png` (مقاس Play: 512×512، صغّرها إن طُلب)
- الرسم الترويجي 1024×500: `public/play/feature-graphic-1024x500.png`
- لقطات الهاتف: `apps/store-assets/play/` (1080×2400)

**نموذج أمان البيانات (Data safety) — الإجابات:**
- يجمع بيانات؟ نعم → معلومات شخصية: الاسم ورقم الهاتف (لإنشاء الحساب، غير مشاركة مع أطراف ثالثة، غير مستخدمة للتتبع)
- الصور: يرفعها المستخدم لإعلاناته (محتوى من إنشاء المستخدم)
- البيانات مشفرة أثناء النقل؟ نعم (HTTPS)
- يمكن طلب حذف البيانات؟ نعم → رابط الحذف أعلاه
