# تشغيل المعاينة المعزولة — إعداد غير مفعّل

`compose.preview.json` ملف Compose مستقل؛ لا تدمجه مع ملف الإنتاج.
لم تُنشأ الخدمة أو البروكسي أو حساب قاعدة البيانات بواسطة هذا الملف.

## متطلبات التفعيل

- صورة مبنية ومختبرة من فرع المعاينة، مثبتة بمعرّف digest في `TRBHH_PREVIEW_IMAGE`.
- `TRBHH_PREVIEW_DATABASE_URL`: حساب منفصل، SELECT فقط على قاعدة البيانات الصحيحة. فحص الإقلاع يرفض حسابات الكتابة؛ لا تستخدم حساب الموقع الحالي كحل بديل.
- `TRBHH_PREVIEW_AUTH_SECRET`: قيمة جديدة مستقلة. لا تستخدم كلمة المرور التي ظهرت في الصور أو أي سر إنتاج.
- تحفظ المتغيرات في ملف سري خارج المستودع، داخل مجلد المعاينة المعتمد، بصلاحية 0600. لا تطبع `docker compose config` العادي في سجلات عامة؛ يمكن استخدام `config --quiet` للتحقق دون كشف القيم.
- تحقق من خلو المنفذ المحلي 4188 ومن الموارد، وأن صورة التشغيل لا تحتوي أسرارًا مخبوزة أثناء البناء.
- خذ نسخة احتياطية من إعدادات المعاينة وصورتها السابقة قبل التحديث، ثم جهز بروكسي HTTPS مستقلًا بعد اختبار الخدمة محليًا. لا تعدل إعدادات أو مجلدات `/root/trbhh`.

الملف يربط المنفذ بـ127.0.0.1 فقط، ولا يركب ملفات الإنتاج أو مفاتيح الدفع أو Redis. لا يحد هذا الملف وحده اتصالات الخروج الشبكية؛ يبقى فحص المسارات وعزل حساب قاعدة البيانات مطلوبين قبل النشر. التشغيل التلقائي بعد الفشل معطل أثناء مرحلة التحقق.

## حدود هذه المرحلة

هذه معاينة قراءة مع نموذج محلي، وليست بيئة اختبار كتابة مكتملة. تجربة حفظ الإعلانات والإدارة والدفع تحتاج قاعدة اختبار مستقلة وبيانات عامة منقحة وحسابات اختبار ومزودي دفع ورسائل وهميين أو تجريبيين؛ لا تشغّل وضع الإنتاج على قاعدة الموقع لتحقيق ذلك.

## الرجوع

أوقف خدمة `app` في مشروع `trbhh-preview` باستخدام هذا الملف وملف الأسرار المعتمد فقط. ثم أعد الصورة السابقة التي اجتازت الاختبارات إن وُجدت، أو اترك الخدمة متوقفة وأزل مسار البروكسي الخاص بالمعاينة فقط. لا تستخدم أوامر حذف مجلدات أو volumes، ولا توقف مشروع الإنتاج.

## التحقق الحالي

اختبارات `tests/unit/preview-compose.test.ts` تتحقق من عقد الإعداد محليًا. لا تُعد بديلًا عن `docker compose config --quiet`، وتشغيل الصورة على الخادم، وفحص الصحة والمسارات والوسائط وإثبات رفض الكتابة فعليًا. لم تُجر هذه الخطوات الخادمية بعد.
