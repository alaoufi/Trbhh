# معاينة إدارة الوصول المحلية

لقطات من مكوّن `AccessControlWorkspace` الحقيقي وتنسيقات التطبيق، بتاريخ 22 سبتمبر 2026. جميع الأسماء والمعرفات والأدوار وسجل التدقيق هنا **بيانات تجريبية**؛ الشريط الأصفر يوضح ذلك. الحزمة تفاعلية في المتصفح، بلا استيراد وحدات الخادم أو بيانات فعلية.

| --- | --- |
| قائمة الأدوار على الحاسوب | [عرض](roles-desktop.png) |
| إسناد الأدوار على الحاسوب | [عرض](assignment-desktop.png) |
| إسناد الأدوار بعرض 390 بكسل | [عرض](assignment-mobile.png) |

تم التحقق عبر تبويبين محليين منفصلين في Edge باستخدام أداة التحكم بالمتصفح، ثم إغلاقهما وإلغاء قياس الشاشة المؤقت:

- التنقل من الأدوار إلى الموظفين وفتح موظف الاختبار.
- اتحاد دورين فعالين، مع دور معطّل ودور تابع لقسم معطّل: 4 أدوار محددة تمنح 5 صلاحيات فعلية فريدة. إزالة دور المحتوى تغيّر المعاينة فورًا إلى 3 أدوار و3 صلاحيات؛ إعادة تحديده تعيد الخمس. تكرر الفحص بعرض الجوال.
- حالة «عرض فقط»: حقول الإسناد وزر الحفظ معطّلة.
- حالة ما قبل التهيئة: يظهر التنبيه، وتتعطل أزرار حفظ الأقسام الثلاثة.
- بعرض 390 بكسل كان عرض المستند 385 بكسل، دون تجاوز أفقي للصفحة في إسناد الأدوار والأقسام.
- إرسال نموذج تجريبي أظهر «تم منع الإرسال · لم يُحفظ أي تغيير»؛ كل نماذج المعاينة تُمنع قبل استدعاء إجراءات React.

إعادة التشغيل من جذر المستودع: `node tests/visual/access-control-preview.cjs --serve`، ثم افتح [المعاينة المحلية](http://127.0.0.1:4323/admin/access-control). أو شغّل الأمر دون `--serve` لإنشاء الحزمة فقط. الملفات المولدة داخل `generated/` مستبعدة من Git. يربط الخادم `127.0.0.1` فقط، يقبل GET فقط، ويمنع الاتصالات الخارجية وإرسال النماذج عبر CSP.

الحدود: هذه مراجعة لعرض المكوّن وتفاعله المحلي؛ لا تثبت حراس التفويض أو معاملات MySQL أو MFA أو كتابة سجل التدقيق في التطبيق الحقيقي. رابط Next استُبدل برابط محلي يحفظ وضع المعاينة، وكل إجراءات الحفظ بدائل فارغة إضافة إلى منع الإرسال. زر البحث لا يرسل؛ يمكن تجربة البحث من معامل `q` المحلي. اللقطات المحفوظة تمثل مساحة العرض فقط؛ تعذر التقاط صفحات كاملة بسبب مهلة أداة المتصفح. التحقق من الحالات غير الظاهرة في اللقطات اعتمد على DOM الحي، ونتائجه مسجلة في [ملف التحقق](verification.json).
