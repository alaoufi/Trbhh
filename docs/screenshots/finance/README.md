التجربة تُظهر عمدًا حالات نقص بيانات الضريبة وفارق هللة وموردين معلّقين لبيان التنبيهات ومنع الإقفال. «غير مكتمل» لا تتحول إلى صفر. هذه لقطات لمراجعة الواجهة وليست فواتير أو عمليات فعلية.

لإعادة المعاينة: `node tests/visual/finance-preview.cjs --serve` ثم [فتحها محليًا](http://127.0.0.1:4321/admin/finance?month=2026-09). الروابط المحلية تعمل على جهاز تشغيل المعاينة فقط.
