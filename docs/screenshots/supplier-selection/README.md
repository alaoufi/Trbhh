# مراجعة اختيار منتجات سلة

هذه الصور من المكوّن الفعلي ببيانات ورسومات تجريبية معزولة، وليست منتجات متجر شعبيات الأولين ولا دليلًا على اكتمال ربطه. جميع طلبات الشبكة محجوبة، عدا صور تجريبية يعيدها الاختبار محليًا. لا خادم تطبيق أو قاعدة بيانات أو أسرار إنتاج في هذا الفحص.

- `desktop.png` / `mobile.png`: الكتالوج والبحث والصور والحالة وزرا المعاينة والإضافة.
- `preview-desktop.png` / `preview-mobile.png`: نافذة تفاصيل المنتج.
- `review-desktop.png` / `review-mobile.png`: ملخص المحدد والتكلفة وسعر البيع والتأكيد اليدوي.
- `verification.json`: نتائج تفاعل على 1440 و390 بكسل، تشمل التركيز، البحث بالاسم/SKU، حفظ الاختيار بين الصفحات وعند الخطأ، وعدم الكتابة قبل التأكيد.

إعادة التشغيل: `node tests/visual/supplier-catalog-browser.cjs` بعد تثبيت الاعتمادات، بوجود Chrome. يستخدم Vite المرفق مع Vitest، وPlaywright وTailwind المثبتة بالمشروع؛ لا يثبّت حزمًا ولا يتصل بمتجر حقيقي.

التحقق من معاملات MySQL والتزامن والتراجع يجري بصورة مستقلة عبر `tests/integration/supplier-selection-mysql.test.ts` في خدمة MySQL المعزولة في CI.
