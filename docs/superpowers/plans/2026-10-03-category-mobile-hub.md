# الأقسام وإدارتها على الجوال

**Goal:** مركز إدارة بسيط بأربع صفحات مستقلة وبطاقات قابلة للاستخدام باللمس.
**Architecture:** الإبقاء على actions وصلاحيات categories وتعريفات الحقول الحالية. /admin/categories مركز؛ /manage للإضافة/التعديل/الظهور؛ /fields لاختيار القسم الفرعي وصفحات الحقول السابقة؛ /ads عرض مقسم بمرشحات؛ /settings نصوص وإعدادات عامة. /create لإضافة قسم فرعي واحد دون تحميل محرر لكل قسم. لا migrations ولا حذف بيانات.
**Tech Stack:** Next.js, React, Prisma, Vitest, Playwright.

- [x] اختبارات التنقل والحراسة وقيم فلترة الإعلانات قبل التنفيذ، ثم تشغيلها وفشلها.

- [x] ضبط redirects لصفحات الحفظ المحددة، الحفاظ على readonly/version/auth guards. حراسة الفلاتر وحصر pagination.

البديل المرفوض: تبويبات داخل صفحة طويلة تحمل كل النماذج والإعلانات. الصفحات الحقيقية أبسط للتنقل والرجوع على الجوال ولا تحمل بيانات غير لازمة.
