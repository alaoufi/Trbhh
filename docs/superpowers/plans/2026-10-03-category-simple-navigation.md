# تبسيط قائمة الأقسام والأدلة

**Goal:** الوصول للمهمة مباشرة من قائمة «الأقسام وحقولها» ثم اختيار القسم المستهدف فقط.
**Architecture:** إعادة استخدام ADMIN_GROUPS في قائمتي الإدارة والموقع. ست صفحات فرعية؛ requirements/display تختاران القسم ثم تفتحان المحرر الحالي. لا جداول أو صلاحيات أو حقول جديدة. التنقل المكرر داخل الصفحة مطوي. تحديث الأدلة الثلاثة حسب الوظائف الموجودة فقط.
**Tech Stack:** Next.js, TypeScript, Vitest, Playwright.

- [ ] اختبارات حمراء: المجموعة المستقلة وصفحاتها وصلاحيتها، طي التنقل الثانوي، أنواع صفحات اختيار الحقول.
- [ ] تحديث admin-nav-def وadmin-navigation وcategory-admin-navigation وworkspace وcategory-admin-filters؛ اختيار رئيسي ثم فرعي، مع روابط مباشرة للمحرر الحالي.
- [ ] تحديث أدلة المستخدم والمتجر والإدارة: خطوات الأقسام والحقول والإلزام والظهور، البحث المطوي، الشريط المتحرك، البلاغات والردود، Location؛ توضيح الصلاحيات وعدم تفعيل الشراء.
- [ ] تحديث اختبارات المتصفح للاختيار الجديد والقائمة الفرعية على الجوال؛ اختبارات موجهة ثم typecheck/lint/tests/build قبل الدفع.
- [ ] نشر Preview ثم نسخة احتياطية واختبار بيانات معزولة ونقل الصورة نفسها للإنتاج مع نقطة تراجع. توثيق SHA والأدلة.

القرار: مجموعة قابلة للفتح بروابط مباشرة، لا قوائم متداخلة داخل قوائم أخرى ولا لوحة شاملة بكل المحررات. البديل ذو التبويبات فقط لا يحقق طلب ظهور الصفحات في القائمة. تفويض المستخدم السابق يسمح بالاستمرار دون توقف لموافقة تقنية روتينية.
