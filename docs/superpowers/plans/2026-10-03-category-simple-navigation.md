# تبسيط قائمة الأقسام والأدلة

**Goal:** الوصول للمهمة مباشرة من قائمة «الأقسام وحقولها» ثم اختيار القسم المستهدف فقط.
**Architecture:** إعادة استخدام ADMIN_GROUPS في قائمتي الإدارة والموقع. ست صفحات فرعية؛ requirements/display تختاران القسم ثم تفتحان المحرر الحالي. لا جداول أو صلاحيات أو حقول جديدة. التنقل المكرر داخل الصفحة مطوي. تحديث الأدلة الثلاثة حسب الوظائف الموجودة فقط.
**Tech Stack:** Next.js, TypeScript, Vitest, Playwright.
