# متابعة البلاغات — تصميم وخطة تنفيذ

**Goal:** تمكين صاحب البلاغ والإدارة المخوّلة من تبادل عدة ردود محفوظة، لجميع البلاغات، دون كشف المحادثة للمبلّغ عنه.
**Architecture:** نعيد استخدام repord_ads وreports والصلاحيات والإشعارات. جدول report_replies إضافي فقط، بمفتاح نوع البلاغ ورقمه؛ لا نخلط المحادثة بدفاع صاحب الإعلان ولا بدردشة الأعضاء العامة. كل قراءة وكتابة تتحقق من ملكية البلاغ أو صلاحية reports، وإيقاف إداري يمنع الردود الجديدة دون إخفاء التاريخ.
**Tech Stack:** Next App Router, Prisma/MySQL, Vitest, Playwright.

البدائل: ربط البلاغ بالدردشة العامة أسرع لكنه يخلط بلاغات العضو، ونظام تذاكر مستقل يكرر البيانات. المختار سجل ردود مرتبط بالبلاغ الحالي. لا مرفقات أو دفع أو حذف بيانات قديمة ضمن المهمة.
الموافقة: طلب العضو تنفيذ الردود المتعددة، مع التفويض السابق للاستمرار والاختبار والنشر إلى الرئيسي دون أسئلة تقنية روتينية.

- [x] اختبار صلاحيات الملكية والقراءة/الرد الإداري، الردود المتعددة، الأنواع، nonce، الإيقاف والمعاينة قبل التنفيذ.
- [x] إضافة report_replies في Prisma وDDL المتسامح فقط؛ عدم تغيير الجداول القديمة.
- [x] خدمة موحدة تقرأ الأصل وتتحقق من المتصل قبل قراءة الرسائل أو الكتابة، وإشعار بلا محتوى حساس ضمن نفس المعاملة.
- [x] صفحة بلاغاتي المرسلة + تفاصيل خاصة + تفاصيل إدارية ونموذج رد مشترك يحتفظ بالنص عند الخطأ.
- [x] إيصال بلاغ الموقع/العضو/الإعلان لصفحة المتابعة، وإضافة روابط الإدارة والحساب والأدلة الثلاثة ومفتاح الإيقاف.
- [x] targeted Vitest، Prisma generate/validate، TypeScript، ESLint، build.
- [x] حفظ عربي، صورة معاينة، نسخة احتياطية وقاعدة معزولة: بلاغ موقع/عضو/إعلان، ردين متبادلين، منع عضو آخر، اختبار جوال.
- [x] ترقية الصورة نفسها إلى الإنتاج ثم smoke وrollback عند الفشل؛ لا شراء حقيقي.

الرسائل لا تُستبدل. المعرّف السري للإرسال يمنع تكرار نفس الإرسال دون منع المتابعة بنفس النص في مناسبة لاحقة. إغلاق إجراء المخالفة لا يحذف المتابعة. الردود تخص صاحب البلاغ فقط؛ الدفاع القديم لصاحب الإعلان يبقى مستقلًا.

اختبار المتصفح المعزول كشف غياب reports:add وreports:edit من دليل الصلاحيات؛ أوقفت بوابة النشر الترقية قبل الإنتاج. أضيفتا إلى SERVICES مع اختبار انحدار يستخدم التعريف الحقيقي؛ لا تمنحان تلقائياً للأعضاء أو المراقبين. نتائج الاختبارات المستهدفة بعد التصحيح: 25/25. البناء وفحص الأنواع ناجحان؛ ESLint بلا أخطاء مع 5 تحذيرات سابقة.
