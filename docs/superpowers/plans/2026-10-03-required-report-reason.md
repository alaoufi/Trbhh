# إلزام سبب البلاغ

**Goal:** لا يُنشأ أي بلاغ بلا اختيار سبب معروف، مع توضيح اختياري حتى 2000 حرف، مطلوب عند اختيار «سبب آخر».
**Architecture:** قائمة مشتركة بين صفحة البلاغ والخادم: أسباب الجدول الحالي وأسباب شائعة تعدلها الإدارة من settings. معرفات مميزة وثابتة لمحتوى السبب بدل القيمة الصفرية المتكررة. نحفظ عنوان السبب في سجل البلاغ والتوضيح في report_replies الخاص ضمن المعاملة نفسها؛ لا توسيع مخطط reports.message ولا تغيير بيانات قديمة. نموذج client يحتفظ بالمدخلات عند الخطأ.
**Tech Stack:** Next.js, Prisma, Vitest, Playwright.

البديل المرفوض: required في المتصفح فقط، لا يمنع الطلبات المصطنعة. لا إرسال بلا سبب حتى لو أرسل المستخدم نصاً فقط. لا اقتطاع للتوضيح ولا نشره للمبلغ عنه. إيقاف المتابعة لا يمنع إنشاء بلاغ جديد صالح.
