# خطة إصلاح قائمة البلاغات وتكثيف الرئيسية

**Goal:** فصل البلاغات المنتظرة عن المعالجة وتصغير إعلانات الرئيسية مع حركة آمنة.
**Architecture:** قراءة آخر رد دون تعديل البيانات القديمة؛ مصدر واحد للعد والقائمة. تطوير AdGrid وHomeCompactStrip الحاليين، دون تغيير البحث أو التصنيف أو ترتيب النتائج.
**Tech Stack:** Next.js / React / Prisma / MySQL / Vitest / Playwright.

- [ ] اختبار فاشل لاستبعاد الرد الإداري السابق وإعادة انتظار متابعة العضو؛ تحديث قائمة الإدارة والتنبيه لنفس استعلام الانتظار، وإتاحة سجل المعالج. حساب العضو يحتفظ بكل محادثاته.
- [ ] اختبار عرض مضغوط للشريط، حركة بطيئة تتوقف عند التفاعل وتقليل الحركة، بطاقات أصغر وبطاقة عريضة دوريًا دون تكرار. مفتاحان إداريان للحركة والتخطيط.
- [ ] تشغيل الاختبارات المستهدفة وTypeScript وlint والبناء، وتحديث الأدلة الثلاثة.
- [ ] التحقق على الجوال والكمبيوتر، ثم CI ومعاينة وصورة تشغيل مثبتة ونسخة احتياطية جديدة قبل النشر.

البدائل: تصغير كل البطاقات وحده لا يحقق تنويع الشكل؛ شبكة غير منتظمة بالكامل تزيد صعوبة التتبع. الخيار المعتمد من طلب العضو: شبكة مضغوطة منتظمة تتخللها بطاقة عريضة وشريط صغير بين دفعتين؛ تبقى قوالب القائمة والمتجر الشخصية دون تغيير.
