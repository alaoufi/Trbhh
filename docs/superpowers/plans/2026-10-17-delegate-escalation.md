# مراسلة المفوض والتحقق المالي

التصميم معتمد من المستخدم: رسالة قابلة للمراجعة والنسخ وفتح واتساب دون إرسال آلي، ضمن الإدارة فقط، وتحتوي المراجع الموجودة دون بيانات العميل أو أسرار الاتصال.

- [x] إضافة مولد رسالة مضبوط ومختبر، وإعادة استخدام مراجع المنتج المحفوظة.
- [x] إضافة مكون موحد إلى متابعة الطلبات والسداد وتفاصيل الطلب السابق. اختيار المستلم في واتساب، دون افتراض أن وكيل اختيار المنتج هو مفوض CJ.
- [x] إصلاح اختبار Sandbox باستخدام cjOrderCode المسترجع من المصدر فقط مع استعلام تأكيد الهوية قبل أي محاكاة، وعدم استخدام واجهات مالية حقيقية أو إنشاء طلب جديد.
- [x] اختبارات الوحدة والعزل، الأنواع، lint والبناء، ثم مراجعة مستقلة.
- [ ] حفظ التعديلات على الفرع غير الناشر. تجهيز نشر كود فقط بعد نتيجة الاختبار الخارجي؛ لا ادعاء اكتمال دفع أو تتبع أو استرداد دون إثبات.

التحقق الخارجي يحتاج تنفيذ المستخدم SSH. الاسترداد ليس له Sandbox موثق حاليًا، ويظل غير متحقق. لا تغييرات في الأسعار أو قاعدة البيانات أو مفاتيح فتح المتجر.
