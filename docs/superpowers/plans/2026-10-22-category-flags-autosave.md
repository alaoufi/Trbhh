# الظهور والإلزام مع الحفظ التلقائي — 2026-10-22

التصنيف P2. طلب المستخدم عرض القيم الحالية وإزالة «دون تغيير»، وجمع الظهور والإلزام في صفحة وسطر واحد وحفظ التعديل دون تحديث الصفحة.

- استخدام المحرر نفسه للقسم الرئيسي والاستثناء الخاص بالقسم الفرعي؛ نسخ الأقسام كلها تتحقق تحت القفل مع تقييد استثناء الفرعي إلى ذلك الفرعي فقط.
- قوائم تعرض ظاهر/مخفي وإجباري/اختياري، والحالة المختلطة صريحة ولا توحّد بمجرد فتح الصفحة.
- كل طلب يغير الخيار المحدد فقط. المخفي اختياري، والإظهار يحتفظ بالإلزام الحالي (اختياري إذا سبق إخفاؤه).
- منع طلب ثانٍ أثناء الحفظ، تحديث النسخ من نتيجة المعاملة، وعدم عمل redirect أو revalidatePath للإدارة. تعريفات الأقسام تُقرأ مباشرة من قاعدة البيانات.
- فشل الحفظ لا يعرض نجاحاً ولا يغير الحالة المؤكدة؛ يطلب إعادة قراءة الحالة قبل متابعة التعديلات لتجنب إعادة محاولة غير آمنة بعد انقطاع الاتصال.
- لا تغيير بالمخطط أو بيانات الإعلانات أو الأموال. عمليات الكتابة الفعلية عند تعديل المشرف فقط.

التحقق: 59 اختباراً مركزاً؛ المجموعة العامة 3631 ناجحاً و9 متجاوزة؛ TypeScript والبناء ناجحان. تجربة المكون الفعلي بمتصفح Edge عند 1440 و390 مع محاكاة الاستدعاء تختبر الحالة المختلطة والإخفاء والإظهار والإلزام وتسلسل النسخ وفشل الاتصال وعدم تجاوز العرض. ليست اختباراً مصادقاً على الإنتاج.
