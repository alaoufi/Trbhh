# فصل مهام الحقول واختيار القسم — 2026-10-23

P2. المستخدم طلب إزالة تكرار مهام الإدارة وتصحيح الإضافة وحذف الأقسام المكررة الخالية من الإعلانات.

- المهمتان المرئيتان: إضافة وتعديل تعريف الحقول، والظهور والإلزام معاً. روابط display السابقة تبقى مقبولة للتوافق ولا تظهر كبطاقة مستقلة.
- لا يظهر رابط محرر الأعلام الجماعي في مهمة إضافة الحقول؛ تلك المهمة تفتح محرر تعريف الفرع فقط مع رابط منفصل لإدارة فروع القسم.
- إدارة الأقسام تعرض قائمة اختيار ثم تفاصيل قسم واحد. إضافة قسم رئيسي جديد في جزء مستقل، وليست عنصراً في اختيار الأقسام القائمة. الحفظ يعيد اختيار القسم نفسه.
- قوائم اختيار الحقول تمرر تعريفات الحقول الكاملة لظهور أعدادها بدلاً من إسقاطها أثناء mapping.
- قراءة الاستخدام منفصلة: scripts/diagnostics/category-usage.cjs يعرض أعداد الارتباطات في الأعمدة الرقمية المسماة category_id/subcategory_id، ويشمل كل حالات الإعلانات دون محتوياتها. لا ينفذ حذفاً أو دمجاً. هذه جرد أولي وليست ضمان عدم وجود أي مرجع بغير هذه الأسماء.

الحذف لم ينفذ: لا اتصال SSH قائم لدى الوكيل. النتيجة السابقة لا تحوي أعداد الإعلانات/الارتباطات. القسمان المخفيان (عقارات والحيوانات الأليفة) ليسا دليل تكرار بحد ذاتهما. يلزم الناتج قبل تحديد عملية حذف محصورة بالمعرفات ومع حماية الارتباطات ونقطة رجوع.

التحقق: خمسة اختبارات سلوك عرض جديدة تفصل المهمات وتمنع تحويل إنشاء الحقول إلى flags وتتحقق من فتح قسم واحد فقط. البناء وTypeScript ناجحان وESLint صفر أخطاء و7 تحذيرات سابقة. تشغيل المجموعة العامة: 3629 ناجحاً و9 متجاوزة و8 حالات انتهت بمهلة؛ إعادة الملفات الثمانية بعمال أقل نجحت كلها عدا فحص Prisma CLI، ثم نجح منفرداً بعد إيقاف فحص تحديث خارجي CHECKPOINT_DISABLE/PRISMA_HIDE_UPDATE_MESSAGE وتدفئة تشغيل CLI. لم تعدل تأكيدات أو مهل الاختبارات. اختبارات العرض الجديدة الخمسة ناجحة منفردة. لم يختبر الجرد على الإنتاج ولم يُنشر التعديل.
