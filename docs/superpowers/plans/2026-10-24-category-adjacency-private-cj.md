# ترتيب المتشابه وحصر CJ بالإدارة

طلب المستخدم: الأقسام المتشابهة متجاورة لتسهيل الدمج، ومنتجات CJ للإدارة فقط. لا دمج بيانات أو نشر مباشر في هذه المهمة.

- ترتيب ثابت للمجموعات عند أول ظهور، يشمل الجذور والفروع والأقسام المخفية، دون تغيير المعرفات أو الأعداد.
- تعطيل الظهور العام في الكود حتى مع وجود قيمة قديمة مفعلة؛ رفض تفعيله عبر الإجراء القديم.
- التحقق من صلاحية products:view قبل قراءة تفاصيل المنتج أو جلب صور المورد.
- استبعاد جميع روابط CJ من استعلام التجارة العام المشترك: العرض والبحث والتوصيات وفهرسة البحث الجديدة. الفهرس القديم يعاد التحقق من أهلية نتائجه عند القراءة.
- لا تعديل على قاعدة البيانات أو الوسائط أو حالة المنتجات أو إجراءات الدفع.
- اختبار فشل قبل الإصلاح، ثم اختبارات الصلاحيات والترتيب ومجموعة المشروع والبناء وفحص الأنواع.

حد التحقق: استعلام SQL مراجع ومختبر بنيوياً، دون تشغيل قاعدة إنتاج أو إجراء شراء. المعاينة الإدارية عبر /cj تبقى متاحة لأصحاب الصلاحية.
