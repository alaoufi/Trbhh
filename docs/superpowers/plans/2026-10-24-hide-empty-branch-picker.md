# إخفاء قائمة الفرع الفارغة

طلب المستخدم: لا تعرض قائمة قسم فرعي فارغة عندما لا توجد فروع للرئيسي.

الإدارة وCJ ونموذج الإعلان يعرضون منتقي الفرع فقط عندما توجد خيارات متاحة للرئيسي الحالي. تغيير الرئيسي يستمر بمسح الفرع السابق كالمعتاد. لا تغيير على تعريف الأقسام أو قواعد التحقق والحفظ، ولا إتاحة مسارات نشر جديدة.

التحقق: اختبارات عرض بدون فروع ومع فروع، وفحوص المشروع والبناء والأنواع. نشر يدوي فقط بعد توفير الكود للمستخدم.
