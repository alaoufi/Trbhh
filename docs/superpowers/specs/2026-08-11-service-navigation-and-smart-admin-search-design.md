# تنظيم خدمات تربح والبحث الذكي — تصميم

## الهدف

إعادة ترتيب خدمات الإدارة والعضو بحسب التخصص، بحيث يصل أي موظف مخول إلى الخدمة من اسمها أو كلمة مرتبطة بها، دون تكرار أو إخفاء إعدادات مهمة داخل تبويبات عامة.

## مبادئ التنظيم

- لكل خدمة مكان إداري رئيسي واحد وعنوان واضح. لا تنقل البيانات ولا تغير صلاحياتها؛ يتغير مسار الوصول فقط.
- تظهر القائمة وفق صلاحيات الموظف الحالية؛ ولا يكشف البحث خدمة أو بيانات غير مخول لها.
- تبقى الروابط القديمة عاملة وتعيد التوجيه إلى المسار الجديد أو التبويب الصحيح، حتى لا تتعطل المفضلات أو الرسائل الإرشادية.
- لا يخص هذا العمل عقار تربح أو فرع `staging`.

## الإدارة

تنظم القائمة إلى مجموعات مستقرة:

1. **الرئيسية والبحث:** لوحة الإدارة، بحث الإدارة، الأرشيف، الدليل.
2. **الأعضاء والصلاحيات:** الأعضاء، محافظ الأعضاء، ربط الحسابات، التوثيق، الأدوار والصلاحيات.
3. **الإعلانات والمتاجر:** الإعلانات، المبوّبة، المكررة، إدارة المتاجر، الإعلانات الترويجية.
4. **المال والمدفوعات:** التقارير المالية، طلبات الشحن، حسابات الشحن البنكية، محافظ الأعضاء، التحويلات والسحب، بوابات الدفع الإلكتروني، التسعير، حملات ومكافآت الشحن، المصروفات.
5. **الحماية والتواصل:** البلاغات، حارس المحتوى، الكلمات المرفوضة، المراسلات، التنبيهات.
6. **النظام:** النصوص، التحقق والرسائل، الإعدادات، السجل الإداري، الأخطاء، النسخ الاحتياطي.

يضاف رابط مباشر «حسابات الشحن البنكية» إلى `/admin/revenue?tab=accounts`؛ فلا تبقى مخفية داخل صفحة الإيرادات.

## البحث الذكي للإدارة

- بحث خدمات ثابت قبل بحث البيانات: يطابق العنوان والكلمات المرادفة والمسار. أمثلة: `الحساب البنكي`، `آيبان`، `بيانات التحويل`، `شحن` → حسابات الشحن البنكية؛ `رسوم تحويل`، `سحب` → التحويلات والسحب؛ `مكافأة`، `عرض شحن` → حملات ومكافآت الشحن.
- تعرض النتيجة اسم الخدمة، وصفاً قصيراً، مسارها الإداري، وزر انتقال مباشر. ولا تظهر إلا إذا سمحت صلاحية الموظف بالخدمة.
- يبقى البحث الحالي للأعضاء والإعلانات والمتاجر والمبوّبة، وتظهر نتائج الخدمات في مقدمة النتائج.

## العضو

- **الحساب والهويات:** لوحة الحساب، هوياتي، الملف الشخصي، توثيق الحساب.
- **الإعلانات والمتجر:** إعلاناتي، المفضلة، متجري.
- **المحفظة والمدفوعات:** محفظتي، الشحن، التحويلات والسحب عند تفعيلها.
- لا تعرض خدمات غير متاحة، ولا تضاعف رابط الخدمة نفسها في أكثر من قائمة.

## القبول والاختبار

- اختبار أن البحث عن «الحساب البنكي» و«آيبان» و«رسوم تحويل» يعرض خدمة الإدارة الصحيحة فقط للمخول.
- اختبار إخفاء نتيجة الخدمة عن موظف لا يملك الصلاحية.
- اختبار وجود الرابط المباشر لحسابات الشحن واستمرار تبويب الإيرادات.
- اختبار عقود ترتيب قوائم العضو والإدارة وعدم حذف أي مسار قائم.
