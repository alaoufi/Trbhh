# خطة المعاينة المرئية لتربح V2

**الهدف:** تمكين المالك من مشاهدة تجربة V2 والتصفح بين الرئيسية والبحث والإعلان وإضافة إعلان والمتجر ولوحة البائع على فرع مستقل ورابط ويب.

**التفويض:** طلب المالك «انشئ لي على فرع وابي اشوفه» بعد تسليم المعمارية والرحلات. التنفيذ هنا معاينة تفاعلية ببيانات تجريبية، بلا اتصال ببيانات الإنتاج أو خدمات دفع/تواصل حية.

**المعمارية:** تطبيق Next.js مستقل قابل للتصدير الثابت داخل `preview-v2/` في فرع `codex/trbhh-v2-preview`. مكونات React ومفردات التصميم قابلة للنقل لاحقًا إلى تطبيق تربح. لا تغييرات في كود التشغيل أو مخطط أو إعدادات نشر V1؛ استُثني مجلد المعاينة المستقل من فحص TypeScript وESLint للجذر. بيئة المعاينة لا تحتاج أسرارًا أو قاعدة بيانات.

**التقنيات:** Next.js وReact وTypeScript وLucide من إصدارات المشروع؛ CSS مشترك وبيانات مثال محلية؛ تصدير HTML على Vercel Preview إذا سمحت صلاحية الحساب المتصل.

## المهام

- [x] بناء أساس مستقل: `preview-v2/package.json` و`next.config.mjs` و`app/layout.tsx`، وإضافة شعار المستخدم دون تغيير الأصل.
- [x] تعريف `lib/demo-data.ts` و`components/ui.tsx` بعقود للبطاقات والبحث والمفضلة، وتسمية البيانات التجريبية بوضوح.
- [x] بناء الرئيسية والبحث في `app/page.tsx` و`app/search/page.tsx`: جميع أقسام الموجز، نتائج فعلية من بيانات المثال وفلاتر وحالة فارغة.
- [x] بناء الإعلان والمتجر: معرض صور، سعر ومواصفات وبيانات بائع، قنوات تواصل تظهر معاينة دون اتصال بأطراف حقيقية، كتالوج قابل للفلترة.
- [x] بناء إضافة الإعلان ولوحة البائع: مسودة محلية، صور من جهاز المراجع، حقول مناسبة للفئة، معاينة ونشر تجريبي لا يرسل للخادم، إحصاءات موسومة كأمثلة.
- [x] إضافة صفحات أو لوحات معاينة للمراسلة والحساب ورصيد الخدمات عند الحاجة لمنع الروابط المكسورة، دون جمع بيانات حقيقية أو تحصيل.
- [x] فحص الأنواع والبناء، ثم تجربة البحث/المفضلة/النشر التجريبي والتصفح على الجوال والكمبيوتر، وإصلاح الملاحظات الظاهرة.
- [ ] رفع الفرع إلى GitHub دون الدمج، نشر نسخة معاينة مستقلة، التحقق من الرابط النهائي وتسليم رابط الفرع والرابط المرئي.

## معايير القبول

الشعار والهوية متسقان والسوق فاتح. لا روابط رئيسية مكسورة، ولا إدخال بيانات إلى Production. نشر المثال لا يدّعي أن الإعلان وصل إلى السوق الحقيقي. لا تسعير باقات أو تمييز مختلق. جميع الصور محلية أو مصادر عامة موثقة، والواجهة تستجيب لعرض 390px والكمبيوتر. صفحات المعاينة تمنع الفهرسة. مصدر الإنتاج ونشره وموارده لا تتغير.
