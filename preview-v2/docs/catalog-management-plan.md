# إدارة التصنيف والحقول — خطة تنفيذ

المجال: معاينة V2 فقط؛ لا وصول لقاعدة البيانات الحية ولا تعديل دفع.

- [ ] دعم الاختيار الواحد والمتعدد في إنشاء الحقول، مع خيارات منفصلة قابلة للإضافة والحذف وإلزامية/إظهار عند الإنشاء. اختبار الإلزامية والقيم غير المسموحة والحفظ والاستعادة.
- [ ] تقليل الفراغات في إضافة الإعلان وإدارة الحقول دون تقليل مساحة لمس المدخلات.
- [ ] قائمة منسدلة في الرئيسية تشمل القسم والفرع، وترتبط بنتائج البحث بالفرع.
- [ ] وحدة تصنيف محافظة: إبقاء التصنيف الصالح، إسناد العناوين الواضحة فقط، وإرسال الملتبس إلى أخرى/أخرى مع علامة مراجعة.
- [ ] جدول إدارة محلي لجميع أمثلة السوق وإعلانات المتصفح: فلترة غير المصنف، بحث، تحديد الظاهر، اختيار الوجهة، تأكيد النقل، تعديل فردي وتراجع عن آخر دفعة. لا تغيير نص الإعلان وصوره؛ أرشفة المواصفات المتخصصة عند تغيير فرع إعلان محلي.
- [ ] تطبيق تعديلات تصنيف أمثلة السوق على الرئيسية والبحث وصفحة الإعلان والمتجر. إظهار فصل البيانات التوضيحية عن المحلية؛ لا الادعاء بتصنيف الإعلانات الحية.
- [ ] اختبارات وحدة ومتصفح للهاتف وسطح المكتب، تحديث الأدلة، ثم نشر المعاينة نفسها بعد فحص الأنواع والبناء.
