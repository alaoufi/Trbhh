# نموذج إعلان في صفحة واحدة

المطلوب: الحفاظ على هوية V2 وحقول الفروع مع إزالة التنقل بالخطوات.

1. اختبار ظهور التصنيف والتفاصيل والصور والمراجعة معاً، وفشله على النموذج السابق.
2. أقسام مرقمة وروابط انتقال داخل الصفحة، دون إخفاء قسم أو أزرار التالي والسابق.
3. إبقاء المسودات والصور والحقول المتخصصة؛ قراءة مسودات version 1 القديمة مع تجاهل موضع الخطوة.
4. فحص الحقول كلها عند النشر، وملخص أخطاء قابل للتركيز وروابط للأقسام.
5. تحديث دليل العضو والمتجر والإدارة واختبارات الفروع، وفحص الهاتف وسطح المكتب.
6. بناء وتفعيل المعاينة المستقلة فقط، دون تغيير الإنتاج أو الدفع أو قاعدة البيانات.
