## قواعد التشغيل والأمان

- اختيار الفرع يحدد الحقول والأمثلة وإلزامية الحقول وإظهار حالة المنتج وطريقة عرض السعر.
- تبديل الفرع يمسح المواصفات والسعر والحالة غير المتوافقة، ويبقي العنوان والوصف والصور والمدينة.
- الإيجار يفتح حقول الدورية والدفعات، وحقل الحمل مشروط بإناث/مختلط، وبيانات البطارية/المدى مشروطة بنوع الوقود.
- المطلوب يستخدم تفاصيل اختيارية؛ المعروض يطلب أساسيات الفرع. الراتب يحتاج دورية عند إدخال مبلغ، والحد الأعلى لا يقل عن الأدنى.
- الحقول الرقمية تقبل الأرقام العربية وتتحقق من المدى والنوع؛ الخيارات محصورة في القوائم والتواريخ تتحقق من صحتها. حدود الأرقام حواجز إدخال عملية وليست قيوداً تنظيمية.
- لا يظهر حقل فارغ أو مخفي أو أجنبي عن الفرع في المعاينة. النصوص تعرض بواسطة React دون HTML خام. لا مفاتيح أو أسرار أو رفع لبيانات أو طلبات خارجية جديدة.
- إعدادات الحقول محلية، متاحة للجميع للتجربة فقط، ولا تمنح صلاحية على الخادم. إخفاء/أرشفة الحقل لا ينفذ حذفاً لبيانات الإعلانات المخزنة. يجب بناء التفويض والتحقق على الخادم عند نقل هذه التجربة للإنتاج.
- قيم الخيارات المتحكمة بالشروط والتسعير محمية من تغيير قيمها؛ يمكن تعديل اسم الحقل أو إظهاره وإلزاميته. القوائم الأخرى قابلة للتعديل، ويرفض حفظ قائمة فارغة. القيم القديمة لا تمحى عند القراءة أو تغيير حالة إعلان آخر. عند تعديل إعلان ذي خيارات لم تعد متاحة، يطلب النموذج تصحيحها صراحة، مع زر لإزالة الاختيارات المتعددة غير المتاحة.
- المسودات القديمة تبقى بنفس المفتاح؛ العنوان والوصف والصور محفوظة. لا تُخمن دلالة الحقلين القديمين spec1/spec2 ولا تحوّلها عشوائياً إلى مواصفات جديدة. يجب مراجعة تلك المواصفات يدوياً عند التعديل.

## الاختبار والتسليم

`npm test` لاختبارات الكتالوج والشروط والتطهير والتحكم. `npm run typecheck` و`npm run build` لفحص النوع والتصدير الثابت. `tests/browser-fields.mjs` اختبار متصفح محلي لجميع الفروع والتبديل والحفظ والجوال والتحكم. المعاينة لا تنشر إعلانات عامة ولا تصل إلى قاعدة البيانات الحية أو وسائل الدفع.
