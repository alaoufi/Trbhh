# معاينة فرع مراجعة تربح

هذه بيئة تجريبية مستقلة طلبها المالك لمراجعة الفرع، وليست نشرًا إلى تربح أو عقار تربح.

- تعمل من `codex/trbhh-audit-fixes-20260910` فقط، بعد نجاح CI للالتزام نفسه.
- يبني GitHub التطبيق ويزرع MySQL فارغة ببيانات مصطنعة، ثم ينقل standalone والبيانات إلى `/root/trbhh-preview-audit`.
- جميع الحاويات والوسائط وقاعدة البيانات والشبكات تابعة لمشروع `trbhh-preview-audit` فقط. لا تتصل قاعدة المعاينة بقاعدة الإنتاج ولا تستخدم ملفاتها.
- التطبيق وقاعدته داخل شبكة بلا خروج إلى الإنترنت؛ خدمة النفق وحدها لها اتصال خارجي. لا تُمرّر مفاتيح الرسائل أو الدفع أو التتبع.
- `TRBHH_PREVIEW_PASSWORD` سر GitHub خاص بحسابَي `preview` و`preview-store`، وهما حسابان عاديان. لا تُحفظ كلمة المرور في المصدر أو السجلات.
- رابط HTTPS التجريبي يظهر في ملخص مهمة المعاينة وفي ملف `preview-url.txt` داخل دليلها على الخادم. الرابط مؤقت وقد يتغير إذا أعيد تشغيل نفق Cloudflare.
- المعاينة تمنع الفهرسة، وتوضح الواجهة أنها بيانات تجريبية. روابط المشاركة الأصلية ما زالت تشير لنطاق الإنتاج؛ ليست جزءًا من اختبار النشر التجريبي.
- لا يوجد اسم نطاق مخصص ولا تغيير DNS أو Nginx الخاص بالموقع الأساسي.

يمكن إيقاف هذه المعاينة فقط من دليلها بالأمر:

```sh
docker compose -p trbhh-preview-audit -f compose.yml stop
```

كل تحديث لاحق يحتفظ بنسخة من إعدادات هذه المعاينة وقاعدتها داخل `backups/` قبل تحديثها. لا يحذف أمر الإيقاف بياناتها، ولا يؤثر على أي مشروع آخر.
